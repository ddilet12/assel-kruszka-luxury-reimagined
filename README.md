# Assel Kruszka Vision

Create a pixel-perfect luxury fashion e-commerce website for the brand:

ASSEL KRUSZKA

REBELLIous ELEGANCE

IMPORTANT:

Use the attached reference image as the PRIMARY visual source.

The website must reproduce the reference image as closely as possible in:

- layout

- spacing

- typography

- proportions

- colors

- image composition

- section order

- navigation

- cards

- buttons

- footer

- visual hierarchy

DO NOT create a generic fashion template.

DO NOT redesign the concept.

DO NOT change the visual direction.

DO NOT add unnecessary sections.

The goal is to recreate the provided reference design 1:1 as closely as possible while making it fully functional and responsive.

1. BRAND / VISUAL STYLE

==================================================

Brand:

ASSEL KRUSZKA

Tagline:

REBELLIOUS ELEGANCE

Style:

- luxury women's fashion

- editorial fashion magazine aesthetic

- premium European fashion house

- sophisticated

- minimal

- feminine

- confident

- high-end

- clean

- timeless

Color palette:

- warm ivory / off-white background

- pure white

- black / near-black typography

- deep burgundy / dark red as the primary accent

- subtle warm beige tones

Avoid:

- bright colors

- excessive gradients

- neon

- overly rounded UI

- cheap-looking ecommerce elements

- excessive shadows

- generic SaaS design

- overly playful typography

Use very subtle borders and shadows.

Typography:

Use an elegant high-contrast serif font for large headlines, similar to:

- Cormorant Garamond

- Playfair Display

- Bodoni-style typography

Use a clean modern sans-serif for:

- navigation

- descriptions

- prices

- buttons

- small labels

The contrast between serif headlines and clean sans-serif body text is essential.
